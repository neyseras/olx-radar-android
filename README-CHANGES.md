# OLX Radar v1.3.1 — что изменилось (только UI/темы, логика не тронута)

## 1. Новые темы (всего теперь 6)
В **Настройки → ОФОРМЛЕНИЕ** добавлены:
- **Изумруд** — тёмная зелёная тема (мятный акцент `#5BE49B`, небесно-голубой вторичный).
- **Аметист** — тёмная фиолетовая тема (лавандовый акцент `#C4A5FF`, розовый вторичный).

Старые темы (Кибернетика, Liquid Glass, Белая, Серая) работают как раньше.
Выбор сохраняется, тёмный режим системы включается автоматически для всех тёмных тем
(в `OlxRadarApp` теперь используется флаг `ThemeMode.isDark`, а не жёсткий список).

## 2. Liquid Glass в новых местах (не только нижняя панель)
- Добавлен `LocalGlassBackdrop` + модификатор `Modifier.glassPanel(shape, blurDp, lensDp)`
  (`LiquidGlass.kt`) — стекло теперь можно включить на любой панели контента,
  а не только на нижнем баре. Работает только в теме Liquid Glass и при включённых
  «Эффектах Liquid Glass», иначе обычная полупрозрачная поверхность.
- Стекло добавлено на:
  - **Находки**: сегмент-переключатель «Подходящие / Отфильтрованные», чипы фильтра
    по радарам («Все» и каждый радар), карточки находок (`FindingCard`);
  - **Радары**: сводная карточка-дашборд и карточки радаров;
  - **ИИ-поток**: карточка текущей обработки и карточки ленты;
  - **Настройки**: все основные секции-карточки (7 шт., включая карточку «ОФОРМЛЕНИЕ»).
- Фоны экранов в теме Liquid Glass теперь прозрачные — виден живой градиент
  под стеклом (раньше экран перекрывал его непрозрачным цветом).
- Нижняя стеклянная панель: тонкая светлая кромка (border) + пилюля-подсветка
  вокруг иконки активной вкладки — сразу видно, где ты находишься.

Модалка Deal Inspector (нижний шит с деталями находки) осталась без шейдер-стекла
намеренно: она в отдельном окне и не имеет доступа к backdrop-слою — там работает
полупрозрачная тема.

## 3. Новая иконка приложения
Заменена вся связка `mipmap-*` (ic_launcher, ic_launcher_round, foreground,
background) во всех 5 плотностях (mdpi…xxxhdpi) на новый чистый радар-эмблем
(кольца + луч развёртки + цель, неоновое свечение, без «телефона в круге»).
Исходник картинки — `icon-new.png` / `radar_icon-media-*.png`.

## 4. Техническое
- `versionCode`/`versionName` → `261119067` (по твоей схеме ГГММДД + счётчик).
- Удалена мёртвая функция-заглушка `glassColor()` из `Theme.kt`.
- Добавлен глобальный флаг `isGlassFxEnabled` (синхронизируется с настройками),
  чтобы новые стеклянные панели уважали тумблер производительности.

## Как собрать
```bash
./gradlew assembleDebug   # или assembleRelease с keystore.properties
```

## Ревизия 3 (261119069) — фикс краша Liquid Glass на Android 15
- Причина: стеклянные карточки внутри отслеживаемого слоя вызывали circular rendering crash (Kyant0/AndroidLiquidGlass issue #100).
- Настоящее преломление теперь только там, где оно безопасно: нижняя панель и боковая навигация.
- Карточки — полупрозрачный «glassy» вид без сэмплирования слоя (визуально стекло сохранено, краша нет).
- Аптечка для любых устройств: Настройки → тумблер «Эффекты Liquid Glass» → выкл (панели станут обычными).
