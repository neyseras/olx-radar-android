**OLX Radar** — это полностью автономное Android-приложение для мгновенного отслеживания новых объявлений на OLX и их глубокого анализа с помощью моделей компьютерного зрения (**Vision AI**). 

Приложение работает **напрямую с вашего смартфона**: никаких внешних серверов, арендованных баз данных, подписок или платных прокси-серверов. Все запросы, парсинг, фильтрация и хранение истории происходят локально на устройстве.

---

## 🌟 Ключевые возможности

### 🤖 1. Мультимодальный ИИ-фильтр (Vision AI)
* **Поддержка любых провайдеров**: прямое подключение к **Groq Cloud** (Llama 3.2 Vision, Qwen 2.5/3.8 Vision), **OpenRouter** (Gemini 2.0 Flash, Qwen 2.5-VL, Llama 3.2), **OpenAI** (GPT-4o-mini, GPT-4o) или **любому совместимому серверу (Custom OpenAI-compatible API)** — vLLM, Ollama, LiteLLM.
* **Анализ реальных фотографий**: модель распознаёт не только текст объявления, но и внимательно инспектирует прикреплённые фото в высоком качестве.
* **Выявление обмана и брака**: мгновенное отсечение лотов с пометками «только коробка», «на запчасти», «после ремонта», «iCloud / MDM lock», а также обнаружение сколов, битых пикселей и полос на экранах.
* **Обязательная валидация (Vision Probe)**: встроенный тест поддержки зрения (микрозапрос 1x1 probe) перед сохранением настроек исключает сохранение неподходящих текстовых моделей.
* **Умный кэш Room**: результаты анализа сохраняются в локальной SQLite/Room базе — повторные проверки того же лота происходят мгновенно без расхода токенов.

---

### ⚡ 2. Отказоустойчивость: Circuit Breaker и Failover
* **Мгновенное переключение (Failover)**: возможность задать **резервного провайдера (Backup AI)** или запасной API-ключ.
* **Circuit Breaker**: при исчерпании лимитов запросов (**HTTP 429 Rate Limit**) или сбое основного API система не блокирует очередь, а временно помечает провайдер как «охлаждающийся» (кулдаун 60 с) и **мгновенно направляет запрос на резервный ключ**.
* **Никаких зависаний**: ответ по лоту возвращается за считанные секунды даже при жестких ограничениях бесплатного тарифа.

---

### 🌊 3. Живой «ИИ-поток» и асинхронная очередь
* **Мониторинг в реальном времени**: интерактивный экран показывает, какое именно объявление и сколько секунд обрабатывается нейросетью прямо сейчас.
* **Фоновая очередь (`AiQueueManager`)**: тяжелые лоты с большим числом фото или медленным ответом автоматически переносятся в очередь фонового пула, не задерживая синхронный обход радаров.
* **Вкладка «В очереди»**: отдельный раздел в ленте с бейджем количества ожидающих лотов и возможностью отменить или запустить обработку вручную.
* **Синхронизация отмены**: удаление лота из ленты моментально отменяет его фоновый анализ, экономя токены и время.
* **Журнал рассуждений (AI Thought Logs)**: полная прозрачность цепочки мыслей нейросети (Chain-of-Thought) с объяснением причин вердикта.

---

### 🎯 4. Продвинутые радары поиска
* **Категории OLX**: точный поиск по официальному каталогу категорий через системные `category_id`.
* **Фильтр по свежести (дате публикации)**: возможность отбирать только новинки (до 24 часов), недавние (до 3 дней), лоты за неделю или любые объявления.
* **Мультивалютный контроль цен**: надёжная проверка границ стоимости с автоконвертацией (UAH, USD, EUR).
* **Слова-маркеры**: гибкие стоп-слова и обязательные фразы с проверкой границ слов (`\b`), исключающие ложные срабатывания.
* **Датчик состояния (Condition Sensor)**: анализ текста на «рабочий / б/у / сломанный / любой» с настраиваемым порогом строгости.
* **Рыночная цена и бейджи выгоды**: автоматический расчёт медианной рыночной цены и индикаторы (`🔥 Суперцена`, `⚡ Выгодно`, `Нормальная`, `Выше рынка`).
* **Поддержка OLX Доставки**: фильтрация и индикация объявлений с возможностью безопасной покупки.
* **Резервное копирование (`.config`)**: экспорт и импорт всех настроенных радаров в JSON-файл в один клик.

---

### 🛡️ 5. Автономность и защита от блокировок
* **Chromium WebView Bridge**: запросы к OLX API выполняются через встроенный контекст системного движка WebView с передачей нативных браузерных cookies и заголовков.
* **Фоновая служба (Foreground Service `dataSync`)**: круглосуточная стабильная работа в фоне с постоянным уведомлением в шторке и кнопками быстрого управления (Пауза / Продолжить / Стоп).
* **Jitter & Exponential Backoff**: рандомизация интервалов опроса (±10%) и адаптивные паузы при сетевых сбоях предотвращают подозрительную активность.
* **Тихие часы**: режим сна, временно отключающий звуковые сигналы в ночное время.

---

### 🎨 6. Дизайн Material 3 и Liquid Glass
* **Четыре темы оформления**:
  * 🪟 **Liquid Glass** — полупрозрачное живое стекло на шейдерах преломления (`io.github.kyant0:backdrop`).
  * 🌌 **Cybernetic Dark** — контрастная неоново-тёмная палитра.
  * ☀️ **Light** — чистая светлая классическая тема.
  * 🩶 **Gray** — сдержанная нейтральная тема.
* **Планшетный режим**: двухколоночный адаптивный интерфейс и боковая панель навигации (Navigation Rail).
* **Инспектор лота (Deal Inspector)**: подробный модальный экран с галереей изображений, аналитикой цены, цепочкой мыслей ИИ и быстрыми кнопками звонка и перехода в OLX.
* **Двуязычный интерфейс**: полная локализация на украинский и русский языки.

## 🔑 Быстрая настройка ИИ

Приложение может работать без ИИ (базовая фильтрация по словам и ценам), но для максимальной эффективности рекомендуется подключить Vision API:

### Вариант А. Groq Cloud (Быстро и бесплатно)
1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com).
2. Создайте API-ключ в разделе **API Keys** (формат: `gsk_...`).
3. В приложении: **Настройки** → **Основной провайдер ИИ** → выберите **Groq**.
4. Вставьте ключ, выберите рекомендованную модель (например, `qwen/qwen3.8-27b` или `llama-3.2-11b-vision-preview`).
5. Нажмите **«Проверить модель на Vision»** и сохраните.

### Вариант Б. OpenRouter (Широкий выбор моделей)
1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) и получите ключ (`sk-or-v1-...`).
2. В приложении: выберите провайдер **OpenRouter**.
3. Вставьте ключ и выберите одну из бесплатных моделей с поддержкой Vision (например, `google/gemini-2.0-flash-exp:free` или `qwen/qwen-2.5-vl-72b-instruct:free`).
4. Нажмите **«Проверить модель на Vision»** и примените.

### Настройка резервного провайдера (Failover)
* В блоке **«Резервный провайдер (Failover)»** включите тумблер и укажите второй ключ или провайдер.
* При исчерпании лимитов основного ключа запросы будут мгновенно перенаправляться на резервный без задержек.

## 🛠 Сборка из исходников

### Требования
* **JDK**: OpenJDK 17 или 21
* **Android SDK**: `compileSdk = 36`, `targetSdk = 34`, `minSdk = 24` (Android 7.0+)
* **Gradle**: 8.12 (в комплекте через `./gradlew`)

### Сборка Debug APK
```bash
./gradlew assembleDebug
```
Файл сборки: `app/build/outputs/apk/debug/app-debug.apk`

### Сборка Release APK
```bash
./gradlew assembleRelease
```
Файл сборки: `app/build/outputs/apk/release/app-release.apk`

Для подписи собственным релизным ключом создайте `keystore.properties` по шаблону `keystore.properties.example`. При его отсутствии сборка автоматически подписывается отладочным ключом.

### Запуск тестов
```bash
./gradlew testDebugUnitTest
```

## 🧱 Стек технологий

* **Язык**: Kotlin 2.0+ (KSP, Coroutines, StateFlow)
* **Пользовательский интерфейс**: Jetpack Compose, Material 3, Accompanist, Kyant0 Backdrop Liquid Glass
* **Архитектура**: Clean Architecture / MVVM, Single-Source-of-Truth
* **Хранилище данных**: Room ORM (SQLite) с миграциями, DataStore / SharedPreferences
* **Фоновые процессы**: Android Foreground Service (`dataSync`), BroadcastReceivers, WorkManager
* **Сетевой уровень**: Chromium WebView Bridge, OkHttp3, JSON/REST API
* **Загрузка и обработка фото**: Coil Compose, Bitmap Compress / WebP / JPEG Base64
* **ИИ & Компьютерное зрение**: OpenAI Chat Completions API protocol (Groq, OpenRouter, Custom Endpoints)
