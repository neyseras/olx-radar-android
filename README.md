Автономное Android-приложение для мгновенного отслеживания и интеллектуального анализа объявлений на [OLX.ua](https://www.olx.ua). Работает непосредственно на мобильном устройстве без сторонних серверов, бэкендов и платных прокси.

В приложение встроен фильтр на базе компьютерного зрения **Groq Vision** (Llama 3.2 Vision / Qwen Vision), который проверяет реальные фотографии лотов, определяет оригинальность, комплектность и дефекты товаров.

---

## 🚀 Основные возможности

### 🤖 1. Интеллектуальный ИИ-фильтр (Groq Vision)
* **Анализ фото и описания лота**: модель компьютерного зрения оценивает реальные фотографии объявления перед отправкой уведомления.
* **Выявление обмана и некомплекта**: мгновенное отсечение лотов с пометками «только коробка», «на запчасти», «после ремонта» или несоответствием фото заголовку.
* **Проверка скрытых дефектов**: обнаружение сколов, трещин и видимых повреждений на экранах и корпусе.
* **Локальный кэш анализов**: результаты проверки лотов сохраняются в локальной базе Room, исключая лишние запросы к API для уже просмотренных товаров.

### ⚡ 2. Живой «ИИ-поток» ссылок (v1.6.0)
* **Мониторинг обработки в реальном времени**: специальная вкладка показывает, какое именно объявление и сколько секунд нейросеть анализирует прямо сейчас.
* **Прямые ссылки на OLX**: каждая карточка содержит кликабельный URL с кнопками быстрого открытия в приложении/браузере и копирования ссылки в буфер обмена.
* **Лента результатов с вердиктом**: список последних проверенных ссылок с процентной оценкой соответствия (`✓ Подходит 95%`, `✗ Отклонено 85%`, `⚡ Из кэша`, `⚠ На проверку`) и развёрнутым текстовым объяснением причин от нейросети.
* **Фильтры ленты**: быстрая фильтрация по одобренным, отклонённым или сомнительным ссылкам.

### 🎯 3. Продвинутые радары и фильтры поиска
* **Категории OLX**: точный поиск по каталогу категорий (электроника, телефоны, компьютеры, авто и т.д.) через официальные `category_id`.
* **Фильтр по свежести (дате публикации)**: возможность отбирать только новинки (до 24 часов), недавние (до 3 дней), лоты за неделю или давние предложения.
* **Фильтр цены с учётом валют**: надёжная проверка границ цен в гривнах, долларах и евро.
* **Обязательные и стоп-слова**: гибкая фильтрация с учётом границ слов (`\b`), исключающая ложные срабатывания.
* **Пульс состояния (Condition Sensor)**: локальный текстовый анализатор «рабочий / сломанный / любой» с ползунком строгости.
* **Защита от спама при старте**: при первом запуске радар фиксирует существующие лоты и присылает уведомления только о новых публикациях.
* **Резервное копирование (`.config`)**: экспорт и импорт всех настроенных радаров в JSON-файл для сохранения или обмена.

### 🛡️ 4. Автономность и отказоустойчивость
* **Chromium WebView Bridge**: запросы к API OLX выполняются через контекст встроенного системного движка WebView с передачей нативных браузерных заголовков и cookies.
* **Фоновая служба (Foreground Service: dataSync)**: стабильный опрос в фоновом режиме с постоянным уведомлением в шторке и кнопками быстрого управления (Пауза / Продолжить / Стоп).
* **Индивидуальные интервалы и Jitter**: настройка таймингов для каждого радара с рандомизацией задержки (±10%) для защиты от блокировок.
* **Экспоненциальный backoff**: автоподстройка пауз при получении HTTP 429 или временных сетевых ошибок.

### 🎨 5. Современный дизайн (Material 3 + Liquid Glass)
* **Четыре темы оформления**:
  * **Liquid Glass** — полупрозрачное живое стекло на базе шейдеров преломления (`io.github.kyant0:backdrop`).
  * **Cybernetic Dark** — неоново-тёмная контрастная тема.
  * **Light** — чистая светлая тема.
  * **Gray** — сдержанная нейтральная палитра.
* **Поддержка планшетов**: адаптивная двухколоночная сетка и боковая навигационная панель (Navigation Rail).
* **Инспектор объявлений (Deal Inspector)**: полноэкранное модальное окно с галереей фото, характеристиками лота, прямыми ссылками и деталями от ИИ.
* **Полная локализация**: русский и украинский языки интерфейса.

## 📱 Вкладки приложения

1. **Находки (Radar)** — лента найденных предложений, прошедших фильтры радаров и одобренных нейросетью, с бейджами выгоды и статуса.
2. **Отклонено (Filtered)** — архив лотов, отсеянных по стоп-словам, ценовым рамкам или забракованных нейросетью (с возможностью восстановить или перепроверить).
3. **Радары (Watches)** — управление списком активных радаров, быстрая настройка интервалов, категорий, фильтра свежести и сводка мониторинга с живым счётчиком запросов.
4. **ИИ-поток (AI Live)** — окно прозрачности работы нейросети: какие ссылки сканируются прямо сейчас, прямые кликабельные URL и архив вердиктов Groq Vision.
5. **Настройки (Settings)** — выбор темы оформления, ввод API-ключа Groq, выбор модели нейросети, настройка тихих часов и режим разработчика с живыми логами.

## 🔑 Настройка Groq Vision API

Приложение может работать как в базовом режиме (по ключевым словам и ценам), так и с подключением нейросети для анализа фотографий:

1. Зарегистрируйтесь бесплатно на [console.groq.com](https://console.groq.com).
2. Создайте API-ключ в разделе **API Keys** (ключ начинается с `gsk_...`).
3. В приложении перейдите на вкладку **Настройки** → **Нейросеть (Groq Vision)**.
4. Нажмите **«API-ключ Groq»**, вставьте скопированный ключ и нажмите **«Сохранить»**.
5. Нажмите **«Проверить соединение»** для подтверждения готовности.

> **Примечание**: Groq предоставляет бесплатный лимит запросов, которого достаточно для круглосуточного отслеживания нескольких десятков радаров.

## 🛠 Сборка из исходников

### Требования
* **JDK**: OpenJDK 17 или 21
* **Android SDK**: `compileSdk = 36`, `targetSdk = 34`, `minSdk = 24` (Android 7.0+)
* **Gradle**: 8.12 (обёртка `gradlew` включена в репозиторий)

### Сборка Debug APK
```bash
./gradlew assembleDebug
```
Собранный APK-файл:
```
app/build/outputs/apk/debug/app-debug.apk
```

### Сборка Release APK
```bash
./gradlew assembleRelease
```
Собранный файл:
```
app/build/outputs/apk/release/app-release.apk
```

Для подписи собственным ключом скопируйте файл настроек:
```bash
cp keystore.properties.example keystore.properties
```
и укажите пути к вашему `.jks` хранилищу. Если файл отсутствует, Gradle автоматически подпишет релиз тестовым ключом.

### Запуск тестов
```bash
./gradlew testDebugUnitTest
```

## 🧱 Стек технологий

* **Язык**: Kotlin 2.0+
* **UI**: Jetpack Compose, Material 3, Backdrop Liquid Glass
* **Асинхронность**: Kotlin Coroutines, StateFlow, Flow
* **База данных**: Room ORM (SQLite) с версионированием миграций
* **Фоновая работа**: Foreground Service (`dataSync`), BroadcastReceiver
* **Сеть и парсинг**: Android WebView Chromium Bridge, OkHttp, JSON API
* **Загрузка изображений**: Coil Compose
* **ИИ**: Groq Cloud Vision API (Llama 3.2 11B Vision / Qwen 2.5 Vision)
